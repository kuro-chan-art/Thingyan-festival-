# 🪔 Thadingyut Festival Website

An interactive website celebrating **Thadingyut, the Myanmar Festival of Lights**, built with HTML, CSS, and JavaScript.

The website combines traditional festive greetings with modern animations, a glowing lava lamp, and background music to create a warm digital celebration.

## ✨ Features

- 🪔 Animated lava lamp with festive visual effects
- 🇲🇲 Burmese and English greeting articles
- 🎵 Background music with play/pause controls
- 🔊 Adjustable music volume, set to 50% by default
- 📱 Responsive layout for desktop, tablet, and mobile devices
- ✨ Interactive animations and a festive dark-and-gold theme

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, `script.js`, and the `assets` folder are in the correct locations.
4. Open `index.html` using the VS Code Live Server extension.

## 🌐 Live Website

Once GitHub Pages is enabled, add your published website link here.

`https://YOUR-USERNAME.github.io/thadingyut-festival/`

Replace `YOUR-USERNAME` with your GitHub username.

## 🎵 Background Music

The website attempts to play background music automatically when the page opens. Some browsers block autoplay with sound, so visitors may need to press the Play music button.

Keep the background music file inside the `assets` folder and ensure its filename matches the audio path in the HTML.

## 📱 Responsive Design

The layout adapts to different screen sizes, presenting the lava lamp and greeting articles in a more readable arrangement on smaller devices.
